猫砂って、**どのトイレを買うか**はさんざん調べるのに、**捨て方は買ってから気づく**んですよね🗑️

先日、Xでこんな疑問をもらいました。

> 鉱物系の猫砂って燃やせないゴミですよね。
> うちの収集は2週間に1度なんですが、**うんち入りの猫砂も2週間置いておくんでしょうか**……？

これ、**言われるまで考えたことがなかった**です😿

調べてみたら、**猫砂の捨て方は「素材」でほぼ決まる**ことがわかりました。

---

## まず大前提：自治体でまったく違います

先に書いておきます。

**猫砂の分別は、お住まいの地域のルールがすべてです。**

- 🏠 同じ鉱物系でも、**燃えるゴミの地域と燃やせないゴミの地域があります**
- 🚮 「ペットの排泄物」として**別の扱い**になる地域もあります

なので、この記事は「**だいたいこうなっていることが多い**」という話です。

最後に**自分の地域の調べ方**も書いておくので、そこだけでも見ていってください🧐

---

## 素材別の捨て方

猫砂は、**燃やせる素材かどうか**で分かれます。

| 素材 | 燃える？ | よくある分別 |
|---|---|---|
| 🌲 **木のチップ** | 燃える | 燃えるゴミが多い |
| 📄 **紙** | 燃える | 燃えるゴミが多い |
| 🫘 **おから・豆腐** | 燃える | 燃えるゴミが多い |
| 🪨 **鉱物（ベントナイト）** | **燃えない** | **燃やせないゴミが多い** |
| 💎 **シリカゲル** | **燃えない** | **燃やせないゴミが多い** |

ポイントは、**うんちが包まれているかどうかは関係ない**ところです。

**砂そのものの素材**で決まります。

### 鉱物系が一番つまずきます

鉱物系（ベントナイト）は、**固まりやすくて、値段も安い**のでよく使われています。

ただ、**燃やせないゴミの地域だと、収集が月2回ということが珍しくありません**。

つまり、**うんちの入った砂を2週間置いておく**ことになります🙄

これ、**買う前には絶対に気づかないやつ**です。

---

## うんちは、砂と分けると一気にラクになります

ここが結論です。

**うんちだけトイレに流して、砂だけためる。**

これだけで、置いておく期間の問題がだいたい解決します🚽

- 🚽 **うんちは水に流せます**（猫の排泄物そのものは流してOK）
- 🪨 **砂は流さずにためる**
- 🗑️ 砂だけなら、**においは出にくい**

猫のうんちは**毎日そんなに大量には出ない**ので、流す手間自体は大したことがありません。

### ⚠️ 「トイレに流せる猫砂」の落とし穴

パッケージに「**トイレに流せます**」と書いてある砂があります。

ただ、これは**流せる＝流していい、ではありません**。

| | |
|---|---|
| 🏢 **集合住宅** | **禁止されていることがあります**。管理規約を確認してください |
| 🚰 **古い配管** | 詰まる可能性があります |
| 💧 **一度に大量** | 流せる砂でも詰まります。**少しずつ** |

浄化槽の場合も、**流さないほうが無難**です。

**流せる砂だから安心、ではない**ところは押さえておいてください🧐

## 収集日まで置くときのにおい対策

砂だけためるとしても、**完全に無臭にはなりません**。

うちでやっていること、調べてわかったことをまとめます。

### ① 袋を二重にする

一番地味で、一番効きます🛍️

**袋の口をしっかりねじって縛る**のがポイントで、ふんわり縛ると意味がありません。

### ② 防臭袋を使う

においを通しにくい素材でできた袋があります。

**おむつ用のものが、そのまま猫にも使えます**。

小分けにして縛ってから、普通のゴミ袋に入れる形になります。

### ③ ふた付きのゴミ箱に入れる

**ペダル式でふたが閉まるタイプ**だと、開け閉めのたびににおいが出ません。

猫がゴミ箱をあさる家は、**ロック付き**のほうが安心です🐈

### ④ 置き場所を変える

**日の当たらない、涼しいところ**に置きます。

ベランダや玄関など、**生活する部屋と分ける**だけでも体感が変わります。

## うちの場合

うちは**システムトイレ**を使っています。

| | 素材 |
|---|---|
| ⬆️ **上の猫砂** | 木のチップ |
| ⬇️ **下のシート** | 紙とポリマー |

どちらも**燃えるゴミとして出せる地域**なので、正直ここでは困っていません🙄

ただ、調べていて「**鉱物系を使っていたら面倒だったな**」とは思いました。

2匹いるので**トイレの数も砂の量も単純に倍**ですし、**収集が月2回だったら確実に詰んでいた**と思います。

## 自動トイレを考えている人へ

**「自動トイレ＝鉱物系しか使えない」と思われがち**ですが、そうでもありません。

- ✅ **おから系・豆腐系が使える機種もあります**（PETKITなど）
- ❌ ただし、**固まらない砂はどの機種も不可**です（機械がすくえないため）

自動トイレに向いている砂の条件はこれです👇

| | |
|---|---|
| 🔹 **粒が細かい** | 5mm以下が目安 |
| 🔸 **しっかり固まる** | 崩れると回収できない |
| ⚖️ **軽すぎない** | 飛び散る・センサーが反応しにくい |

**おから系が使える機種を選べば、燃えるゴミで出せる地域が多い**ので、**ゴミの日が少ない人にはここが決め手**になります🗑️

## 自分の地域の調べ方

**3分で終わります。**

1. 🔍 「**◯◯市 ごみ 分別 ペット**」で検索する
2. 📖 自治体のごみ分別辞典で「**ねこ砂**」「**猫砂**」を引く
3. 📞 出てこなければ、**清掃事務所に電話**する

分別辞典は**ほとんどの自治体がWebに出しています**。

「猫砂」で載っていなくても、「**ペットの排泄物**」「**ペットシーツ**」で載っていることがあります🧐

## やらないほうがいいこと

| | なぜ |
|---|---|
| 🚫 **鉱物系を大量にトイレに流す** | **配管が詰まります**。固まる砂です |
| 🚫 **分別がわからないまま出す** | 回収されずに残されることがあります |
| 🚫 **うんちごと長期間ためる** | においと虫の原因になります |
| 🚫 **生ゴミと同じ袋に入れる** | においが倍になります |

## まとめ

- 🪨 **捨て方は「砂の素材」で決まる**。うんちが入っているかは関係ない
- 🔥 **木・紙・おから → 燃えるゴミが多い**
- ❄️ **鉱物・シリカゲル → 燃やせないゴミが多い**
- 🚽 **うんちだけ流して、砂だけためる**のが一番ラク
- ⚠️ **「流せる猫砂」でも、集合住宅や古い配管では流さない**
- 🔍 **最後は自治体のルールを確認する**

これから猫砂を選ぶなら、**自分の地域の収集日とセットで考える**のをおすすめします。

**収集が月2回の地域なら、燃えるゴミで出せる素材**。

理由は、**においの問題がそもそも発生しないから**です🗑️

買ってから気づくと、**地味に2年くらい付き合うことになる**ので🙄
